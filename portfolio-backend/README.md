# 🚀 Sachin Yadav Portfolio & AI Assistant Backend

Complete Node.js / Express backend with real-time MongoDB database design for contact handling, Google Gemini AI streaming, and visitor analytics telemetry.

## 🛠️ Tech Stack
- **Runtime:** Node.js / Express.js
- **Database:** MongoDB & Mongoose ODM (7 Collections)
- **AI Streaming:** Google Gemini API with Server-Sent Events (SSE)
- **Email:** Nodemailer (Gmail SMTP)
- **Security & Logging:** Helmet, CORS, Express-Rate-Limit, Winston, Morgan

## 🚀 Quickstart
```bash
cd portfolio-backend
npm install
npm start
```
